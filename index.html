Real Estate Database Web App

A web application for browsing, listing, and managing real estate properties — paginated house listings with full details, transactional create/update/delete operations, and a ten-table normalised MySQL schema.

CRUD Operations

GET List Houses

start.php — paginated house listing with multi-table JOIN across House, Address, HouseForSale, and Owner. Fetches rowsPerPage + 1 to detect the next page without a COUNT query.

POST Insert Listing

insert.php — wraps House, Address, HouseFeature, and Owner inserts in a single PDO transaction; rolls back all four if any step fails.

POST Update Listing

update.php — updates House and Address rows, then deletes and re-inserts all HouseFeature rows for the house to handle checkbox changes atomically.

POST Delete Listing

delete.php — deletes a House row; ON DELETE CASCADE propagates to Address, HouseFeature, HouseForSale, Sale, and Owner automatically.
